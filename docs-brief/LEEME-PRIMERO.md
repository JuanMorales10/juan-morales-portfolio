# Portfolio de Juan Morales

Este paquete contiene el brief completo, el prompt de implementación y recursos visuales reales para construir el portfolio profesional de Juan Morales.

## Cómo usarlo

1. Descomprimí el ZIP.
2. Abrí Claude en una carpeta nueva y separada del repositorio de Rienda.
3. Adjuntá la carpeta descomprimida o indicále a Claude que lea `PROMPT-PARA-CLAUDE.md`.
4. Pedile que implemente el proyecto completo y no solamente una propuesta visual.

## Reglas importantes

- El portfolio debe crearse en un repositorio independiente. No modificar el repositorio de producción de Rienda.
- `referencias/CV-anterior-solo-referencia.pdf` está desactualizado. Sirve únicamente para rescatar datos que coincidan con el brief actual.
- `perfil/foto-perfil-linkedin.jpg` es la mejor resolución disponible desde LinkedIn, pero sigue siendo una copia de 400 x 400. Usarla provisoriamente y reemplazarla por el archivo original si Juan lo consigue.
- Las capturas de `rienda/capturas-producto/` son material real preparado para mostrar el producto. Los importes y nombres visibles son datos demostrativos, no métricas comerciales verificadas.
- No inventar clientes, resultados, testimonios, facturación ni proyectos.

## Datos que todavía faltan

- Correo personal de contacto.
- Usuario o URL de GitHub.
- Dominio definitivo del portfolio.
- Foto profesional original en alta resolución.
- Otros proyectos reales que Juan quiera mostrar.
- Repositorios, videos o explicaciones de esos proyectos.

El sitio puede implementarse sin esos datos, pero deben quedar centralizados como campos pendientes y ocultarse de producción cuando corresponda.
